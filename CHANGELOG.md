# Changelog

All notable changes to the TOON Dataset Compiler are documented in this file.

The project follows Semantic Versioning (SemVer).

Version Format

```
MAJOR.MINOR.PATCH
```

Example

```
1.4.2

Major : Breaking architectural changes

Minor : New features

Patch : Bug fixes and documentation
```

---

# Versioning Policy

Every release should include:

- Summary
- Added
- Changed
- Improved
- Deprecated
- Removed
- Fixed
- Compiler Impact
- Dataset Impact

# Release Checklist

Every release should satisfy the following requirements.

Documentation

- Updated README
- Updated CHANGELOG
- Updated ROADMAP

Compiler

- Specifications validated
- Architecture reviewed
- Version incremented

Dataset

- Validation passed
- Quality thresholds satisfied
- Optimization completed

Testing

- Regression tests passed
- Schema tests passed
- Graph tests passed
- Serialization tests passed

Benchmarks

- Dataset evaluated
- Coverage measured
- Quality report generated

# Semantic Versioning

Major Version

Increment when

- Architecture changes
- Compiler redesign
- Breaking schema changes

Minor Version

Increment when

- New modules
- New compiler passes
- New ontology domains
- New generators

Patch Version

Increment when

- Documentation updates
- Bug fixes
- Small improvements
- Validation corrections

---

# Historical Archive

Older releases should never be modified.

Corrections should be recorded in new releases.

Every release remains reproducible and traceable.

# Notes

The TOON Dataset Compiler prioritizes long-term architectural stability.

Breaking changes should be rare.

Every release should improve:

- Engineering intelligence
- Dataset quality
- Knowledge coverage
- Reasoning quality
- Compiler reliability
- Documentation quality

without compromising reproducibility or maintainability.
